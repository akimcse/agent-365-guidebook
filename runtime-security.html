Defender · 런타임 위협 탐지

Copilot Studio · Microsoft Foundry · 로컬 에이전트의 런타임 위협 탐지·차단은 서로 다른 4개 계층에서 일어납니다 — ① Copilot Studio 네이티브, ② Defender for Cloud AI 위협 방지(모델 레벨), ③ Security for AI · Agent 365(에이전트 런타임), ④ Defender for Endpoint(로컬). 계층마다 탐지 엔진 · 대상 · 표출 포털 · 라이선스가 다릅니다.

라이선스 표기제품 기본 해당 제품 라이선스만으로 사용Agent 365 Microsoft Agent 365 필요시행 예정 문서상 Agent 365 요구이나 아직 미시행추가 별도 구매·종량제(PAYG) 필요
SECTION 01

4계층 탐지 아키텍처계층별 상이

AI 에이전트의 런타임 위협 탐지·차단은 서로 다른 4개 계층에서 일어납니다. 계층마다 탐지 엔진 · 대상 · 표출 포털 · 라이선스가 다르므로, “어느 계층에서 탐지되는가”를 먼저 정해야 어느 포털을 봐야 하는지가 결정됩니다.

🔑 계층을 가르는 기준은 “무엇을 보느냐”입니다. ①·②는 콘텐츠(프롬프트·응답 텍스트)를 보고, ③은 행위(어떤 도구를 어떻게 호출했는가)를 보며, ④는 엔드포인트에서 실행되는 에이전트를 봅니다. 따라서 같은 jailbreak라도 계층에 따라 다른 곳에 기록되며, Copilot Studio 에이전트의 프롬프트 공격은 AI.Azure_Jailbreak.* 경고를 생성하지 않습니다 — 해당 경고는 Azure AI 모델 배포(Foundry Models)를 대상으로 하기 때문입니다.
