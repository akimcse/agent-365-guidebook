유형별 커버리지 지도

AI 에이전트를 어디서 실행되는가 기준으로 네 유형으로 나누고, 각 유형이 단계별 라이선스에 따라 어디까지 로깅·차단·대응되는지를 한 장에 정리합니다. 각 단계의 기능명을 누르면 해당 기능을 다루는 심화 문서로 이동합니다.

기능 색 구분 발견 · 인벤토리 로깅 · 규정 준수 위협 헌팅 · 위험 평가 차단 · 대응 커버리지 칸에 마우스를 올리면 조회 포털과 로그 테이블이 표시됩니다
Native · Microsoft 플랫폼

네이티브 에이전트

Copilot Studio · Azure AI Foundry — 신원·감사·원문·tool call·차단이 플랫폼에 기본 통합되어 있으며, 관측 데이터를 별도 계측 없이 전송합니다.

1
신원 · 인벤토리 (플랫폼 내장)Copilot Studio / Foundry
Copilot Studio: Entra Agent ID 자동 발급 · 감사 기본 ON · Monitor 분석(360일) Foundry: tracing/observability → App Insights(입력·출력·tool call·토큰, opt-in) 확인 위치 — Copilot Studio > Monitor · Entra 관리센터 > Agents · Azure AI Foundry 포털 > Observability · Azure Monitor
2
프롬프트·응답 원문 · 내용 규정 준수＋ Purview E5 (+PAYG)
DSPM으로 프롬프트·응답 원문 — CS=트랜스크립트(28일), Foundry=Enterprise AI apps 수집 민감정보(SIT)·파일 참조 + 민감도 라벨 · DLP for AI · 커뮤니케이션 규정 준수 · eDiscovery 확인 위치 — Purview 포털 > DSPM · Activity Explorer
3
사용 · 신원 차단＋ Agent 365 (Entra ID P2)
사용(관리) 차단: M365 관리센터 Registry 차단·차단 해제 (차단 효과는 제작 도구별로 다름) 신원 차단: Conditional Access for Agents + ID Protection (Agent Risk=High→토큰 차단) 확인 위치 — M365 Admin center > Agents · Entra 관리센터 > 조건부 액세스
4
위협 헌팅 · 런타임 차단Agent 365 (Defender)
AgentsInfo 인벤토리·위험 점수·보안 권고 · Advanced Hunting KQL 조사 런타임 차단: Defender Security for AI 실시간 보호 (도구 호출을 실행 전 평가·차단) 확인 위치 — Defender 포털 > Advanced Hunting · Settings > Security for AI

Cloud app · SaaS GenAI

SaaS AI 앱 · 에이전트

ChatGPT 웹 · Gemini Enterprise · Claude.ai 등 웹으로 접근하는 AI 앱과 그 위에서 동작하는 에이전트 — MDCA+MDE로 발견·차단, Purview·Entra Suite로 내용을 확보합니다.

1
발견 (Shadow AI)MDCA + MDE P2
Cloud Discovery(MDE 로그 기반)로 어떤 GenAI SaaS를 쓰나 발견 · 사용량 · 위험도 확인 위치 — Defender 포털 > Cloud apps > Cloud Discovery
2
차단 · 대응MDCA + MDE P2
앱을 미승인(Unsanctioned) 태깅 → MDE Network Protection으로 엔드포인트 접근 차단 (반영 최대 3시간) 확인 위치 — Defender 포털 > Cloud app catalog
3
위협 헌팅 · 위험 평가MDCA + MDE P2
앱 위험 점수(90개 이상 요소)·컴플라이언스 속성 평가 · Cloud Discovery 이상 탐지 범위 주의: CloudAppEvents 헌팅은 App connector·세션 제어 연결 앱만 — ChatGPT 웹 등은 DeviceNetworkEvents·검색 수준 위험 점수로 한정 확인 위치 — Defender 포털 > Cloud app catalog · Policies > Shadow IT
4
내용 로깅 · DLP · 프롬프트 원문＋ Purview (+PAYG) ＋ Entra Suite일부 Preview
DSPM으로 프롬프트·응답 내용·민감정보(SIT) 로깅 Endpoint DLP가 업로드 파일을 SIT·민감도 라벨 기준 전체 스캔하여 감사·경고·차단 (Edge 기본 · Chrome·Firefox는 Purview 확장 설치 시) GSA + TLS 검사 — Generative AI Insights가 프롬프트 본문 로깅(이벤트당 최대 65KB) Preview · Scan with Purview로 브라우저 외 앱·API 경로까지 내용 검사 Preview Collection policy의 콘텐츠 캡처는 첨부 파일 본문 미포함 · GSA 단독으로는 파일명·본문 미기록 확인 위치 — Purview 포털 > DSPM · Activity Explorer · Entra 관리센터 > GSA

Registry Sync (가시성)Agent 365

2
차단 · 대응Agent 365 (Entra P2)

디바이스에서 동작하는 로컬 AI 에이전트

Claude Code · GitHub Copilot CLI · Cursor 등 엔드포인트에서 실행되는 에이전트 — MDE 기반 발견 · 런타임 보호 · 준비태세 관리를 제공합니다.

1
발견 · 인벤토리MDE P2
발견: CLI·Desktop·IDE·VS Code 계열 + MCP 서버 구성 자동 발견 · 인벤토리·구성 가시성 확인 위치 — Defender 포털 > Assets (또는 Advanced Hunting AgentsInfo)
2
차단 · 대응 (런타임 보호)MDE P2 + Intune런타임 Preview
MDE 런타임 보호: 프롬프트 인젝션·위험한 도구 호출을 엔드포인트에서 탐지(Audit)·차단(Block 모드) Intune을 통한 Sandbox 구성 가능 (아웃바운드 통신 통제 포함) 확인 위치 — Defender 포털 > 알림·디바이스 타임라인 · Intune 관리센터
3
위험 점수 · 보안 권고 · 위협 헌팅＋ Agent 365 (또는 E7)
발견된 로컬 에이전트에 위험 지표·준비태세(Posture) 관리·보안 권고 부여 Advanced Hunting — 에이전트 관측성 로그 KQL 헌팅·조사 확인 위치 — Defender 포털 > Advanced Hunting
4
프롬프트 원문 · 내용 검사 (GSA 경유)＋ Entra Suite ＋ Purview (+PAYG)Preview
GSA 클라이언트 + TLS 검사로 트래픽 인스펙션 → Generative AI Insights가 MCP/AI 트래픽의 프롬프트·응답 전문 로깅(최대 65KB) Scan with Purview — GSA를 SSE 집행 지점으로 파일·텍스트 내용 검사하여 감사·차단 엔드포인트 DLP 없이 브라우저·앱·API 트래픽 커버 — 단 GSA 단독은 내용 미검사(Basic=MIME 타입만) · HTTP/1.1 한정 · 로컬 MCP 서버는 불가(원격만) 확인 위치 — Entra 관리센터 > GSA > Gen AI Insights · 콘텐츠 정책 · Purview 포털 > Activity Explorer
